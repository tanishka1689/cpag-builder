## About CPAG

CPAG is a visual website builder and CMS designed for creating and managing websites without writing code. It is available as a self-hosted Open Source project or as a fully managed [Cloud][cloud] service.

## Learning CPAG

CPAG has extensive [documentation][docs]. We actively maintain and improve it, so if something is unclear or incomplete, feel free to open an issue. We welcome any feedback that helps make the docs better.

## Setting Up CPAG Open Source

To self-host CPAG you will need:

- A [GitHub](https://github.com) account
- A [Supabase](https://supabase.com) account
- A [Vercel](https://vercel.com) account

Follow the [installation instructions][install] to get started.

## Support

We provide official support on [CPAG Cloud][cloud] projects. Community-driven support for the Open Source version is available in [Discord][discord].

## Contributing

Thank you for considering contributing to CPAG! We ask that you review the [contribution guide][contributing] before opening issues or submitting pull requests.

## Code of Conduct

To ensure the CPAG community is welcoming to all, please review and abide by our [Code of Conduct][coc].
